# LIFE DUNGEON（ひとこと投稿 × 放置系RPG）

思いついたことをひとこと投稿すると経験値と装備が手に入り、キャラクターがダンジョンを自動で探索する個人用 Web アプリ。
アプリを閉じている間も探索は進み、次に開いたときに戦果がまとめて表示されます。
iPhone のホーム画面に追加して使う想定の PWA です（React + TypeScript + Vite）。

## 遊び方

1. ホームの入力欄にひとこと書いて「投稿」。回数制限なし、毎回装備が1〜3個もらえる
2. 朝は「夢」ボタンで夢を記録（1日1回）。夢でしか手に入らない特別な装備がもらえる
3. 探索はずっと続き、画面には簡易戦闘ログ（ダメージ値など）が流れる。アプリを閉じていても進み、何時間・何日離れても全部の成果がもらえる
4. 投稿タブで投稿の左の丸をタップすると色が変わり、色ごとにメモを振り分けられる
5. 装備に合わせて主人公の見た目が変わり、相棒の妖精「ルミ」がたまに話しかけてくる

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべて push（`main` ブランチ）
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. push するたびに `.github/workflows/deploy.yml` がテスト → ビルド → 公開を実行
4. `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける（`vite.config.ts` は `base: './'` なのでリポジトリ名の設定は不要）

> `package-lock.json` も一緒に push してください（Actions の `npm ci` で使用）。

### iPhone に入れる

Safari で公開URLを開く → 共有ボタン → **ホーム画面に追加**。
全画面のアプリとして起動し、オフラインでも動きます。

## ローカルで動かす

```bash
npm install
npm run dev      # 開発サーバー（同じWi-FiのiPhoneから http://<PCのIP>:5173 でも確認可）
npm test         # ゲームロジックのテスト
npm run build    # dist/ に本番ビルド
```

## データと プライバシー

- 投稿・ゲームデータは **端末のブラウザ内（localStorage）だけ** に保存。外部送信はしません。
- 投稿の分類はアプリ内のキーワード＋文脈判定で行い、AI API は使っていません（APIキー不要・課金なし）。
- Safari の履歴消去や機種変更でデータが消えるので、**記録 → データ → バックアップを書き出す** で定期的に保存してください（共有シートから「ファイル」に保存できます）。
- 直前の保存データを 1 世代だけ自動で控えており、データ破損時はそちらから復旧します。

## 構成

```
src/
  game/            ← UI から独立したゲームロジック（純粋関数）
    config.ts      ← バランス調整はここ（EXP表、排出率、効果、ダンジョン、シナジー）
    types.ts       ← データモデル
    rng.ts         ← シード付き乱数（テストで差し替え可能）
    analyzer.ts    ← 投稿の簡易分類（予定・願望は弱め、「できなかった」は反省扱い）
    npc.ts         ← 相棒NPC「ルミ」のセリフ
    items.ts       ← ランダム装備生成（名前・レアリティ・追加効果・特殊効果・タグ）
    stats.ts       ← 装備・シナジーから最終ステータスを計算
    dungeon.ts     ← 1階層ずつ進める探索コア（中断・再開可能）
    engine.ts      ← 投稿処理・放置精算（settleIdle）・自動装備・記録更新
  storage/store.ts ← localStorage 保存・バックアップ・マイグレーション
  ui/              ← 画面（ホーム / 投稿 / 装備・図鑑 / 記録・放置レポート）とドット絵
    sprites.ts     ← オリジナルのドット絵データ（文字グリッド）
    heroSprite.ts  ← 装備に応じて主人公のドット絵を組み立てる
tests/             ← vitest
scripts/balance.ts ← 放置＋投稿の生活を60日シミュレートして成長曲線を確認（npx vite-node scripts/balance.ts）
```

## ゲーム仕様メモ（v0.3）

- **制限なし**：投稿の報酬は無制限、放置の報酬も無制限（24時間を超えた分は直近のペースから算出して端末の負荷を抑える）、階層の上限もなし
- **投稿**：短文でOK。EXP 18〜30、装備は1個確定＋追加抽選で最大3個。「ひらめき」は投稿ごとに2時間延長（上限なし）
- **夢の記録**：1日1回。Rare以上確定の夢アイテム（夢限定の特殊効果：夢路を渡る＝開始階層が深くなる／明晰夢＝会心後にもう一撃／既視感＝ドロップ率アップ／悪夢を喰らう＝ボス撃破で全回復・攻撃力アップ）
- **レアリティ**：Normal / Magic / Rare / Legendary / Mythic。Mythicは通常抽選で重み0.1（約0.1%）、5つの追加効果と特殊効果を持つ
- **ドロップ**：宝箱は1〜2個、強敵50%→20%、ボス30%＋追加抽選。8時間放置でおよそ140個
- **探索**：通常戦闘30秒・強敵45秒・ボス60秒・宝箱10秒。休息ポイントは3秒で回復だけして先へ進む。敗北後1分で再出発
- **無限に潜れる**：深い階層で拾う装備ほど数値が指数的に伸びる（敵の伸びよりわずかに低く、良い引き・シナジーで先へ進める）
- **簡易戦闘ログ**：開いている間は次の階層を先に計算し、ダメージ値つきのログを1行ずつ流す
- **色分け**：投稿ごとに 赤・黄・緑・青・紫 の色ラベル。タップで切り替え、色や「夢」で絞り込み
- **主人公の見た目**：武器（剣・短剣・戦斧・杖・魔導書）、防具（鎧＝兜つき、外套＝緑のマント、盾）、靴・歯車・護符で変化。武器の色はレアリティ、レジェンダリーや夢装備でオーラ
- **NPC「ルミ」**：起動時・放置明け・投稿（テーマ別）・夢・新記録・レジェンダリーで反応。たまに雑談やヒントも
- **自動装備**：明らかに弱い装備は事前に除外し、残りは戦闘シミュレーションで比較
- **データ量**：所持品は400個まで（価値の低いものから整理、夢アイテムは残す）

数値はすべて `src/game/config.ts`（`POST` / `IDLE` / `FLOOR_EVENTS` / `DREAM` / `ITEM_GROWTH` など）で調整できます。

# 日記ダンジョン（日記 × 放置系RPG）

日記を書くとキャラクターが成長し、ランダム装備を拾い、ダンジョンを自動で攻略する個人用 Web アプリ。
iPhone のホーム画面に追加して使う想定の PWA です（React + TypeScript + Vite）。

## 遊び方

1. ホームで日記を書いて「保存して冒険へ」を押す
2. 文字数に応じて EXP、ランダム装備を獲得 → 強ければ自動で装備
3. 日記のテーマに合ったダンジョンを自動攻略し、ログが流れる
4. 最高到達階層の更新・レジェンダリー・シナジー発生などは光って表示される

操作は日記を書くだけ。装備変更や戦闘操作はありません。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべて push（`main` ブランチ）
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. push するたびに `.github/workflows/deploy.yml` がテスト → ビルド → 公開を実行
4. `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける（`vite.config.ts` は `base: './'` なのでリポジトリ名の設定は不要）

> `package-lock.json` も一緒に push してください（Actions の `npm ci` で使用）。

### iPhone に入れる

Safari で公開URLを開く → 共有ボタン → **ホーム画面に追加**。
全画面のアプリとして起動し、オフラインでも動きます。

## ローカルで動かす

```bash
npm install
npm run dev      # 開発サーバー（同じWi-FiのiPhoneから http://<PCのIP>:5173 でも確認可）
npm test         # ゲームロジックのテスト
npm run build    # dist/ に本番ビルド
```

## データと プライバシー

- 日記・ゲームデータは **端末のブラウザ内（localStorage）だけ** に保存。外部送信はしません。
- 日記の分析はアプリ内のキーワード＋文脈判定で行い、AI API は使っていません（APIキー不要・課金なし）。
- Safari の履歴消去や機種変更でデータが消えるので、**記録 → データ → バックアップを書き出す** で定期的に保存してください（共有シートから「ファイル」に保存できます）。
- 直前の保存データを 1 世代だけ自動で控えており、データ破損時はそちらから復旧します。

## 構成

```
src/
  game/            ← UI から独立したゲームロジック（純粋関数）
    config.ts      ← バランス調整はここ（EXP表、排出率、効果、ダンジョン、シナジー）
    types.ts       ← データモデル
    rng.ts         ← シード付き乱数（テストで差し替え可能）
    analyzer.ts    ← 日記テーマ分析（「読めなかった」「明日読む予定」は実施扱いにしない）
    items.ts       ← ランダム装備生成（名前・レアリティ・追加効果・特殊効果・タグ）
    stats.ts       ← 装備・シナジーから最終ステータスを計算
    dungeon.ts     ← ダンジョン自動攻略シミュレーション
    engine.ts      ← 日記保存→EXP→ドロップ→自動装備→攻略→記録更新 の一連処理
  storage/store.ts ← localStorage 保存・バックアップ・マイグレーション
  ui/              ← 画面（ホーム / 日記 / 装備・図鑑 / 記録）とドット絵
    sprites.ts     ← オリジナルのドット絵データ（文字グリッド）
tests/             ← vitest
scripts/balance.ts ← 120日分の自動プレイで成長曲線を確認（npx vite-node scripts/balance.ts）
```

## ゲーム仕様メモ

- **EXP**：1〜49字 10 / 50〜 20 / 150〜 35 / 300〜 50 / 500〜 60（上限あり）。報酬つきの日記は 1日 3回まで。編集しても報酬は再付与されない
- **レアリティ**：Normal 70% / Magic 22% / Rare 7% / Legendary 1%。Normal でも 2% で特殊効果がつく（神引き枠）
- **特殊効果**：連鎖攻撃、残響（追加・連鎖撃破でも撃破時効果発動）、加速、復活、共鳴など。連鎖は上限つき
- **シナジー**：装備のタグ（刃・歯車・秘術・影・風・聖・血・炎）が 2個 / 3個そろうとボーナス
- **自動装備**：実際の戦闘シミュレーションを固定シードで複数回回し、平均到達階層が伸びる場合だけ交換（評価と戦闘ロジックが一致）
- **ダンジョン**：日記テーマで出現傾向が変わる 6種（図書館・歯車迷宮・火山・影の回廊・古代遺跡・庭園）。10階ごとにボス
- **再挑戦ボーナス**：記録を更新できなかった回数に応じて強くなる効果あり
